# Kalimat

Arabic crosswords and word searches for iPhone, iPad, Android and the web.

## Layout

- `ios/`: the Apple app, content packs, tools and App Store material
- `android/`: the Android app (Kotlin, Jetpack Compose)
- `web/`: the website
